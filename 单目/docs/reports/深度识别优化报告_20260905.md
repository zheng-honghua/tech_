## 算法及深度使用

1. 从空托盘RGB-D标定帧提取参考多边形，存入可选 `tray_roi_polygon` 字段，坐标跟随处理缩放。旧标定文件没有此字段时仍兼容旧行为。
2. 当前ROI与参考重合不足参考面积50%时，返回 `tray_roi_reference_mismatch` 并清除稳定计数；需要核实位置及重新标定。
3. 当前ROI面积不超过参考的1.5倍时保留当前ROI，以适应正常平移；超过时使用交集，限制桌面背景错误并入托盘。不是依据标注数量强制分割出指定物块数。
4. 后续仍用原始有效深度、相机内参和托盘平面计算前景高度、点云三维尺寸、平面法向和面拓扑。RGB轮廓补全不变成有效深度，不生成虚假吸附表面。
5. 没有修改深度有效率、RGB-D同步、平面漂移、形状置信度或吸附面安全门限。只有RGB-D且 `PICKABLE`、`selected=true` 才能驱动运动；本轮全部离线，没有相机/机械动作。

最初试验为固定ROI交集：新场景数量匹配29/31，但在托盘位置变化的旧场景中裁掉了边缘物块，因此没有作为最终实现。中间的 `stage21-multi-new-roi`、`stage21-oldmulti-roi`、`stage21-oldmulti-matched-roi` 是试验产物；**最终数据以 `*-final` 为准**。最终保留适应正常平移的版本，数量匹配26/31，并通过旧场景回归。

## 新数据训练试验

调查发现旧训练与实时推理的裁剪留白、平面标定和分割路径并不一致。本次按实时路径提取了特征，用于检查这种偏差是否影响训练；未直接覆盖生产模型。

- 清单550条＝495物块＋55空托盘；旧 `pilot-01` 一张四棱锥RGB缺失。针对494个可读物块RGB-D文件对检查，没有完全重复。
- 原动态ROI实验得到395个单实例；固定交集ROI实验得到425个单实例，69帧非单实例及1帧缺文件。接受单实例不等于标注一定正确；没有删除拒绝帧。
- 固定ROI特征试验：训练215个（pilot-01＋pilot-03每类前20个中符合筛选者）；验证124个（pilot-02）；时间顺序留出86个（pilot-03每类后10个中符合筛选者）。未分出的帧不能消失在端到端成功率分母中，以下仅是已提取特征的分类诊断。
- 独立KNN的k=1/3/5，验证正确数分别79/81/78，留出60/60/55。v4回放参考为96/124及61/86。
- v4追加215个运行时特征的候选为95/124及63/86；没有稳定胜出，保留原v4。候选：`models/experimental/rgbd/geometry-rgbd-runtime-aligned-candidate-20260905.npz`，仅供实验。
- 历史v4训练来源可能与旧批次重叠；pilot-03末段也是同次拍摄。不能称为独立泛化测试。候选特征分类与最终混合几何复核也并非完全相同的统计口径。
- 本机OpenCV未提供 `cv2.ml`，随机森林分支未运行；未安装新依赖。完整输出 `output/rgbd-aligned-anchor-0905/learners.json`。

上述特征缓存属于固定ROI候选试验，不是最终自适应ROI模型的训练结果；没有把候选性能写成最终程序提升。

## 使用与复现

继续使用 `models/stable/rgbd/geometry-rgbd-multipose-v4.npz` 与 `config/d415-reviewed-20260905.yaml`。用当前相机位置的空托盘 `--background-dir` 创建新标定才会获得参考ROI；只有旧 `--rgbd-calibration` 且无参考多边形时保持旧算法。相机/托盘明显移动后要重新采空托盘；参考不是机器人外参标定，不能使用离线生成的单位变换执行机械动作。

在项目目录运行（输出目录需尚不存在）：

```powershell
.\.venv\Scripts\python.exe scripts/review_rgbd_replay.py --data-root data/rgbd-multi-scenes --batch multi-04 --batch multi-05 --background-dir data/rgbd-pilot/pilot-03/empty_tray/20260905T073448182680Z_d415-000000436 --model models/stable/rgbd/geometry-rgbd-multipose-v4.npz --config config/d415-reviewed-20260905.yaml --output-dir output/stage21-replay-next

# 旧算法消融：相同参数另选输出目录，并增加 --legacy-roi。
.\.venv\Scripts\python.exe scripts/compare_rgbd_composition.py --before output/stage21-multi-new-before --after output/stage21-replay-next --output output/stage21-comparison-next.json
```

`review_rgbd_replay.py` 调用与 `rgbd-review` 相同的联系表生成器；仍须实际打开RGB/深度图复核。训练路径调查可用 `scripts/investigate_rgbd_accuracy.py --output <新目录> --anchor-roi`；这里 `--anchor-roi` 是固定交集实验，不是最终自适应方案。`--reuse-features` 仅用于本轮已完成特征数组但JSON导出中断的恢复，不用于其他数据/代码版本。

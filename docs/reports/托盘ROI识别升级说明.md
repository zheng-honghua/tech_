# 白色托盘 ROI 识别升级

## 目标

RGB-D 流水线现在只处理白色托盘底面和内沿的物块。托盘外的备用物块、桌面、线缆和电脑不再进入分割、分类或抓取计算。

## 处理逻辑

1. 从 RGB 图中查找位于画面内部的大型冷白色矩形。
2. 沿矩形向内收缩到托盘内壁，生成托盘 ROI。物块压在内沿时，位于托盘底面的主体部分仍会保留。
3. 在 ROI 内使用 Lab/HSV 与托盘底色的色差生成物块支持区。
4. 过滤托盘边框形成的细长色差带，然后与深度高度前景取交集。
5. 空托盘平面拟合、平面偏移检查和深度有效率统计均只使用 ROI，不再被 RGB/深度视场黑边干扰。
6. 找不到托盘时闭锁输出，`health.reason=tray_roi_not_found`，不回退到全画面识别。

标注图会用黄线显示 ROI，ROI 外自动变暗，便于直接检查范围。`health.json` 新增 `tray_roi_valid`、`tray_roi_area_ratio` 和 `tray_valid_depth_ratio`。

## multi-01 实拍回归

- 10 帧均正确定位白色托盘。
- 每帧候选数从 9–15（平均 12.6）降为固定 3 个，与真实物块数一致。
- 托盘外误检由多个降为 0。
- 托盘 ROI 内深度有效率约 97%–99%，全画面约 58% 的黑边不再导致质量拒绝。
- 形状组合完全正确 4/10，这是分类模型的后续优化项，不是 ROI 遗留误检。
- 旧空托盘与当前场景仍有约 2.84–3.10 mm 平面偏移；超过 3 mm 的帧继续安全拒绝抓取。

## 使用要求

- 正式运行前，在相机、支架和托盘的当前位置重新拍摄空托盘。
- 相机画面必须看到托盘四周，不得让托盘边界超出画面。
- 白色托盘不得被大面积遮挡；检测不到 ROI 时禁止抓取。

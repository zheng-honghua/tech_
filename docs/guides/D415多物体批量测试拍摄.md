# D415 多物体批量测试拍摄

这个工具用来采集“一帧中有多个物块”的 RGB-D 模拟比赛场景。它记录整个场景的类别和数量，不会混入单件分类训练集。

## 启动

在项目根目录打开 PowerShell，执行：

```powershell
.\.venv\Scripts\python.exe -m sorting_vision.cli rgbd-multi-capture `
  --batch-id multi-01 `
  --composition "三棱柱:2,四棱锥:1,圆锥:1" `
  --captures-per-scene 10 `
  --interval-ms 500
```

`三棱柱:2` 表示画面中有 2 个三棱柱。可使用中文名称或英文协议 ID，项之间用中英文逗号分隔。默认保存至 `data/rgbd-multi-scenes`。

程序默认使用这台 D415 已验证的彩色 `1920×1080@30` 和深度 `640×480@30`。如果 RealSense Viewer 中更换了流配置，可在命令后显式加上：

```powershell
--color-width 1920 --color-height 1080 --depth-width 640 --depth-height 480 --fps 30
```

## 拍摄操作

- 摆好与 `--composition` 完全相符的物块，等待画面显示 `READY`。
- 按 `B` 以 500 ms 间隔自动拍满 10 帧；按 `P` 可暂停。
- `SPACE` 只保存当前一帧。`F` 强制保存仅用于调试，质量验收时不要使用。
- 一组拍满后，重新改变物块的位置、旋转、间距和接触方式，再按 `N` 进入下一个独立布局。
- 按 `Q` 退出。再次执行相同命令会自动续拍未完成的场景。

## 保存内容

```text
data/rgbd-multi-scenes/
├─ scenes.jsonl
└─ multi-01/scene-0001/capture-0001_.../
   ├─ color.png
   ├─ depth.npy
   ├─ depth-preview.png
   ├─ metadata.json
   └─ scene.json
```

`scene.json` 保存类别数量、场景号、连拍序号、深度有效率和同步误差。它只有“场景组成”标注，没有每个物块的边界框或掩膜，因此适合验证检测数量和分类，不能直接用于监督训练多目标分割。

空托盘帧仍使用 `rgbd-capture-assistant` 采集。本工具不接受“空托盘”作为多物体组成。

## 建议拍摄量

每种类别组合至少拍 20 个独立布局，每个布局连拍 3–10 帧。独立布局要覆盖分开、贴合、轻度遮挡、边缘位置和不同稳定面。连拍帧只用于测稳定性，评测划分时必须以 `scene_id` 为单位，不能把同一布局拆到训练集和测试集。

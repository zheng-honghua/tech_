# 单目 / 双目视觉工作区

本仓库现按相机方案拆分为两个并列工作空间：

- `单目/`：拆分前的完整工程，包含当前代码、模型、本地数据、历史产物、虚拟环境及未提交修改。
- `双目/`：从单目工程复制的可复用开发基线，包含源码、配置、模型、脚本、测试、夹具和项目文档，不包含本地采集数据、缓存与历史输出。

进入对应目录后再执行安装、测试和命令。注意：`单目/.venv` 是拆分前环境的完整保留副本，但 Windows 虚拟环境的启动器包含旧绝对路径，移动后不能直接使用；继续单目开发前需要在 `单目/` 中重建虚拟环境。

例如，为双目工作空间建立独立环境：

```powershell
Set-Location .\双目
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
```

> `双目/` 当前仅是复用基线，尚未实现双相机同步、标定、配准、识别融合或抓取坐标变换，不能把第二摄像头结果直接用于机械运动。

# D435if换机、换平台与重新标定

更新：2026-10-02。换相机或安装位置会改变成像、深度和特征分布。旧D415 v4保留作对照，不能凭stable目录名认为已通过新D435if环境。

## 1. 哪些变化需要重新核验

| 变化 | 需要核对／重做 |
|---|---|
| 设备／镜头／焦距／RGB裁剪或尺寸 | 内参、畸变、坐标转换和模型输入 |
| 相机位置／角度／料盘定位 | 平面、空间外参、ROI与背景 |
| 深度档位／比例／对齐方式 | SDK内参、深度单位、孔洞和分辨率 |
| 灯光／曝光／白平衡 | 背景、颜色原型与输入分布 |
| 机器人／吸盘／机械坐标 | camera-to-robot、杯径、余量、工作区 |
| 平台临时转比赛 | 重新标定、数据划分与严格验收 |

不要把不同安装下的像素ROI、外参、背景直接复制成新平台配置。

## 2. 设备和档位先验证

```powershell
Set-Location "C:\Users\d114\Desktop\tech_\monocular camera"
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli `
    --config config\d435if-initial.yaml camera-live `
    --source realsense
```

先确认当前设备、请求档位和实际图像。Viewer核对档位后关闭，避免占用。D435if深度没有RGB式自动对焦；对齐上采样造成块状不代表失焦，也不代表获得更细深度信息。

## 3. 重采空盘与测量

重新拍完整空盘RGB-D，检查盘内有效深度和图深对齐，拟合平面。实测机械坐标并验证相机到机器人变换；默认单位矩阵仅开发使用。主链步骤见[RGB-D教程](RGBD数据采集与训练.md)。

如需双机，还要在另一个工程完成其内参／外参及背景；本工程的单目标定不能代替双机标定。

## 4. 新相机数据与模型

同shape多色、同色多shape、不同实体和姿态，补暗面／高光／孔洞／边缘／接触。按实体和批次隔离训练、校准和最终测试，连拍不跨集合。旧模型与新模型在同一冻结输入、同分母上比较。

重新提取与分割语义匹配的特征，记录模型契约、原始来源、失败样本和校准策略。新候选先存experimental，未验收不替换默认。

## 5. 验证顺序

软件环境→相机读流→图深与单位→空盘平面／ROI→单物块数量和轮廓→颜色与形状→真实抓取面→时序稳定→实际机械坐标与互锁。每一步保留失败原因和实际图像。

运行时health失败会阻止选目标；不要关闭这些门来增加PICKABLE数量。软件测试通过不证明现场标定或机械执行精度。

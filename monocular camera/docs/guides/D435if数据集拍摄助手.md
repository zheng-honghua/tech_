# D435if单相机逐类拍摄助手

更新：2026-10-02。rgbd-capture-assistant只采一台RealSense的RGB＋深度。本工程没有侧RGB采集；双视角操作在另一个工程。

## 1. 使用前准备

固定相机、料盘和灯光，关闭Viewer及其他占用程序；选择实际支持的流档位。每批先拍空盘。相机未安装依赖时在本工程安装.[realsense]，环境见[完整手册](单目工程完整使用手册.md)。

## 2. 启动

```powershell
Set-Location "C:\Users\d114\Desktop\tech_\monocular camera"
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli `
    --config config\d435if-initial.yaml rgbd-capture-assistant `
    --dataset-root data\rgbd-new `
    --batch-id train-set-20261002 `
    --start-label empty_tray `
    --target-per-label 10
```

需要覆盖流时传color-width／height、depth-width／height和fps，当前参数列表见CLI索引。相机档位改变后重新核标定与背景。

## 3. 拍摄步骤

1. 清盘，选择empty_tray，等READY，空格保存。
2. 放一个物块，按数字或N/P选择窗口列出的真实形状。
3. 手离开、物块放稳，READY后空格保存。
4. 每次换独立姿态，不连拍同一摆放凑目标数。
5. Q退出，读取保存路径和分类计数。

数字、N/P、A切换方式以窗口提示和当前列表为准；F为诊断强制保存，会记录覆盖。--auto-advance仅在达到目标后换类，不自动判断标签或自动拍照。

## 4. READY与质量

稳定帧、画面运动、深度有效率、RGB-D同步是采集门。READY不保证真实标签、物块局部深度、平面或可抓。缺空盘拒绝普通物块；先保存空盘。反光、遮挡或深度孔洞先修现场，不直接放宽质量门。

## 5. 保存与续拍

每组有color.png、depth.npy、metadata.json及深度预览；根目录manifest记录批次和标签。复用同batch续拍读取已有计数；换条件建新批次。错标签记录样本并审查，不只删照片。

这个助手没有双机专用split／instance-id／color-id参数；需要实体和颜色划分时在采集计划和审查记录中明确，并给训练／校准／测试独立目录或批次。不要照抄双机脚本参数到这里。

## 6. 拍完做什么

```powershell
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli rgbd-dataset-audit `
    --data-root data\rgbd-new `
    --output-report output\capture-audit-20261002.json
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli `
    --config config\d435if-initial.yaml rgbd-review `
    --results-root output\rgbd-replay-20261002 `
    --output-dir output\capture-review-20261002
```

先按[视觉审查教程](视觉审查流程.md)逐样本回放到output/rgbd-replay-20261002，再生成并实际打开联系表。完整格式、平面标定、训练见[RGB-D教程](RGBD数据采集与训练.md)，多物体见[场景采集](D435if多物体批量测试拍摄.md)。

# 多物块RGB场景预测教程

更新：2026-10-02。predict-scene用于一张RGB图中的多个分离物块。它提供二维实例和类别，不能凭RGB输出机器人可执行深度。

## 1. 输入条件

物块完整可见、背景较简单、相互有间隙；真实接触／遮挡会造成合并或误拆。先准备实际data/input/scene.jpg，再运行：
```powershell
Set-Location "C:\Users\d114\Desktop\tech_\monocular camera"
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli predict-scene data\input\scene.jpg `
    --model models\stable\rgb\geometry-rgb-morph-color.npz `
    --backend opencv `
    --output-dir output\scene-20261002
```

多个物块不应交给单物块predict-image。--json-only输出机器可读结果；完整参数见[CLI索引](CLI命令与参数索引.md)。

## 2. 逐对象检查输出

输出目录有总result.json、标注图及每对象裁剪／掩膜／结果资料；文件名以代码和artifacts为准。记录：
- 真正物块数量与检出数量。
- 同一物块是否拆成多实例，接触物块是否合并。
- 类别正确、错误或unknown。
- 盘沿、手、阴影是否成为物块。
- 每对象轮廓和裁剪是否完整。

整张图只要有一件正确不代表整盘正确。数量、分类、分割、拒识分别统计。

## 3. 结构线诊断

```powershell
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli geometry-scene-structure-audit `
    --data-root data\rgb-scenes `
    --output-dir output\scene-structure-20261002
```

输入目录需放实际场景照片。结构线／顶点用于开发诊断；反光、纹理、阴影与曲面近似不能直接算真实棱。联系表实际看图见[审查流程](视觉审查流程.md)。

## 4. 接触／遮挡怎么办

先记录合并和误拆的帧，不按候选棱线单独分物块。补同色接触、异色邻接和不同遮挡等级的数据，并保留不确定实例。需要空间归属时采真实RGB-D，主视深度缺失不通过补RGB照片伪造。

本单目工程没有侧相机融合；需要双视角时进入[双相机工程](../../../stereo%20camera/docs/guides/双相机工程完整使用手册.md)。

## 5. 性能与比较

相同图片、模型、后端、线程和分辨率下计时。区分模型推理和整盘处理，记录对象数量；不能把单裁剪推理耗时称整盘P95。训练／校准／测试按实体和批次隔离，避免场景连拍泄漏。

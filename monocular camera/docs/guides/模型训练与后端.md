# 单目模型训练、校准与后端

更新：2026-10-02。RGB照片与RGB-D样本使用不同训练器；新候选保存experimental，不覆盖旧模型。

## 1. 数据隔离

明确拟合／概率或拒识校准／最终测试，按实体与批次隔离，连拍同划分。通用单目训练器不会根据双机metadata.split自动筛选；传独立拟合目录或明确batch-id。LOO和训练回放不代替独立测试。

## 2. RGB训练

```powershell
Set-Location "C:\Users\d114\Desktop\tech_\monocular camera"
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli geometry-audit `
    --data-root data\rgb-fit `
    --output-report output\rgb-audit-20261002.json
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli geometry-train `
    --data-root data\rgb-fit `
    --feature-set edge-topology `
    --output models\experimental\rgb-candidate-20261002.npz `
    --output-report output\rgb-fit-20261002.json
```

目录按形状存RGB图。legacy／edge-topology／structure-topology语义独立，改预处理后重新提取和拟合。单图预测见[教程](单图预测使用说明.md)。

## 3. 主RGB-D训练

```powershell
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli `
    --config config\d435if-initial.yaml geometry-rgbd-train `
    --data-root data\rgbd-fit `
    --strict-single-object `
    --fused-edges `
    --baseline-output models\experimental\rgbd-baseline-20261002.npz `
    --output models\experimental\rgbd-candidate-20261002.npz `
    --output-report output\rgbd-fit-20261002.json
```

输入color／depth／metadata完整样本。strict-single-object拒绝多实例，fused-edges增加RGB与真实深度支持特征；baseline-output同样本对照。base-model追加旧数据必须记录来源，不能默认混入旧D415样本。

## 4. 校准与应用评估

本单目工程没有dual-fusion-fit或侧视模型。独立校准接受门，冻结后测试全部帧含unknown和失败。raw类别、接受正确率、覆盖、实际shape_id和抓取状态分别评价；报告错误接受、宏召回、P95及实际看图。

D435if旧v4仅迁移基线。新参数不能因接受数量增加就宣称改善，需控制错误接受与安全状态。具体格式见[RGB-D教程](RGBD数据采集与训练.md)。

## 5. 可选CNN

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[cnn-train]"
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli geometry-cnn-train `
    --data-root data\rgb-fit `
    --output models\experimental\cnn-candidate-20261002.pt `
    --epochs 30 `
    --output-report output\cnn-fit-20261002.json
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli geometry-cnn-export `
    --checkpoint models\experimental\cnn-candidate-20261002.pt `
    --output-dir models\experimental\cnn-export-20261002 `
    --precision fp16 `
    --output-report output\cnn-export-20261002.json
```

CNN是可选实验，需对应依赖和真实数据。INT8另需明确校准data-root，不能用最终测试量化校准。OpenVINO推理安装.[cnn]，路径指完整导出目录。

## 6. 后端测速

```powershell
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli geometry-benchmark `
    --data-root data\rgb-test `
    --backend opencv `
    --model models\stable\rgb\geometry-rgb-morph-color.npz `
    --batch-size 1 `
    --warmup 20 `
    --iterations 200 `
    --output-report output\rgb-latency-20261002.json
```

batch-size=12可测12裁剪批次，但不是完整整盘／采集／网络／机械耗时。记录后端、设备、线程、预热、输入尺寸与P95，并检查类别和接受口径一致。

# 单目环境、PowerShell与相机排错

更新：2026-10-02。两个工程都有sorting_vision包，先确认当前目录、Python和可编辑安装来源。

## 1. 目录与解释器

```powershell
Set-Location "C:\Users\d114\Desktop\tech_\monocular camera"
Test-Path .\.venv\Scripts\python.exe
.\.venv\Scripts\python.exe `
    -c "import sys, sorting_vision; print(sys.executable); print(sorting_vision.__file__)"

```

都指向单目目录才继续。包路径错时在单目工程重新pip install -e ".[dev,realsense]"；环境不存在才创建，移机后重建失效的环境。激活不切目录，显式本地Python最清楚。

## 2. PowerShell命令

不复制PS或>>提示符。优先单行，含空格路径加引号；多行反引号在行尾且后无空格，最后一行不续行，误入等待Ctrl+C。CLI --config放子命令前。

激活可选：
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
& ".\.venv\Scripts\Activate.ps1"
```

## 3. UVC设备

接好设备，关闭相机／Viewer／会议／旧预览程序，依次用camera-live --source uvc --camera-index 0、1、2确认画面，每次结束前一个。Windows名称顺序不是OpenCV索引。缺设备、占用、驱动、索引都可能导致打开失败，不单凭一行DSHOW警告定因。

## 4. RealSense设备

主机由SDK打开，非UVC索引。No device connected检查USB／设备识别；缺pyrealsense2安装本工程.[realsense]；Couldn't resolve requests在Viewer确认流组合后关闭Viewer再试。不要同时改档位、相机位置、曝光和模型。

## 5. 深度／检测失败

| 现象 | 先查 |
|---|---|
| WAIT | 稳定、有效深度、同步、空盘 |
| DEPTH_INVALID | 原深度、比例、距离、平面及图深对齐 |
| NO_GRASP_SURFACE | 面积、平整度、吸盘和边缘余量 |
| unknown | 掩膜、训练分布和distance／margin拒识 |
| selected=false | 稳定帧、health、互锁及可抓候选 |
| 读不到文件 | 工作目录和真实样本路径 |
| 特征契约错误 | 模型与分割／特征匹配，不关检查 |

深度伪彩块状不直接说明失焦；不要填造孔洞绕过安全门。

# 小型测试图集使用说明

更新：2026-10-02。rgb目录保存早期RGB几何／混合场景图，用于开发、软件回归和历史模型复现。RGB-D原始采集在data，包含原深度和metadata。

## 怎么使用

单件图使用predict-image，场景使用predict-scene；命令见[单图教程](../docs/guides/单图预测使用说明.md)和[场景教程](../docs/guides/多物块场景预测使用说明.md)。训练／评价脚本使用明确数据目录，不自动把所有fixtures加入拟合。

## 结果怎么解释

同批开发图已反复查看，不能当独立新实体测试或比赛准确率。RGB图不提供三维测量精度、真实抓取深度或机械验收。

## 增加夹具

少量明确授权、审查并标注的数据才作为回归夹具；记录原始来源、标签和使用用途。大批相机照片／深度包保留独立数据备份，避免与小图集混淆。

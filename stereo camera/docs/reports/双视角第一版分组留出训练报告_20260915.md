# 双视角第一版分组留出训练报告（2026-09-15）

## 结论

第一版实拍数据已经完成可复现的诊断训练和回归测试。程序按“采集批次 × 形状类别”分组，在每组内用固定随机种子 `20260915` 留出3组照片；源数据没有被移动、改名或改写。

本次共读取546个非空盘样本，形成36个可用分组：438组训练、108组回归测试。OpenCV RTrees优于分组距离KNN并被保存为实验模型，但该模型不能进入正式运行：11类注册表中的`cylinder`完全缺失，全部源样本仍为`human_reviewed=false`，测试也是同批次随机留出而不是独立实体留出。

## 数据和拆分方法

| 项目 | 结果 |
|---|---:|
| 非空盘源样本 | 546 |
| 批次×类别分组 | 36 |
| 每组随机留出 | 3 |
| 训练样本 | 438 |
| 回归留出样本 | 108 |
| 固定种子 | 20260915 |
| 已观察类别 | 10 |
| 缺失类别 | `cylinder` |

留出选择不是依赖目录遍历顺序的普通洗牌，而是按“种子、分组名、样本绝对标识”的SHA-256排序取前三个。因此在数据和种子不变时，重复运行会得到完全相同的108组留出样本。

## 数据问题

1. `cylinder`四个颜色均没有样本，完整11类模型无法训练。
2. 蓝色批次写成了`train-bule-set01-20260915`，其`color_id`和`instance_id`也为`bule`。正式颜色训练前必须统一为`blue`。
3. 当前`instance_id`使用了`bule/green/red/yellow`，没有按实体A/B区分。因此无法证明模型能泛化到同色的另一件实体。
4. 全部546个物块样本仍为`human_reviewed=false`。本次为了诊断训练入口而显式允许未审查数据，不能据此生成正式模型。
5. 当前只有四种颜色；既定正式验收要求五种颜色。
6. 各批次缺失组合如下：
   - 蓝色：`triangular_prism`、`square_pyramid`、`cylinder`；
   - 绿色：`cylinder`；
   - 红色：`cone`、`cylinder`；
   - 黄色：`octahedron`、`cylinder`。
7. 本次随机留出来自相同日期、相同平台和相同实体批次，只能叫回归测试，不能叫最终留出或比赛准确率。

## 实际视觉审查

已实际打开并检查最终生成的36张联系表（编号001至036），覆盖全部108个留出样本。每一行同时检查俯视RGB、俯视深度、侧视RGB及绿色掩膜边界。

审查结果：

- 108组中未发现空图、损坏图或整幅深度缺失；俯视深度里物块均可见。
- 最终侧视掩膜能够贴合红、黄、蓝、绿物块，未再把整段料盘边、机架或地面作为主体。
- 调试过程中发现绿色物块和靠盘边物块会被旧背景差分与料盘边缘连成一体，因此增加了彩色组件优先和凸包轮廓清理；最终联系表已按新算法重新生成并全部复核。
- 部分样本紧靠或跨到料盘边缘，例如蓝色`hexagonal_prism/sample-0001`、绿色`cone/sample-0013`、红色`hexagonal_prism/sample-0015`、黄色`pentagonal_pyramid/sample-0015`。物块仍完整可见，但这些姿态容易把盘边和阴影带入运行时ROI，后续数据应增加盘内中部姿态并使用三维投影ROI训练。
- 部分姿态仅凭侧面轮廓存在真实歧义，例如侧放的棱锥与圆锥、五/六棱柱以及三棱柱与四棱锥。没有发现可以仅靠修改标签解决的系统性错误。
- 画面外的AprilTag、夹具和机架没有进入最终彩色物块掩膜。

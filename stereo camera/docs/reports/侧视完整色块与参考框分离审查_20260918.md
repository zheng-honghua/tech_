# 侧视完整色块与参考框分离审查（2026-09-18）

## 为什么侧视图有很多方框

旧侧视标注同时绘制搜索矩形、三维包围体投影、RGB线段候选和深度支持图边。青色包围体是几何参考，**不是识别出的真实物块形状或真实棱线**。它会对圆锥、棱锥也画近似盒状参考，不能按框的形状判断分类结果。

此外旧侧视先在主点云投影ROI里分割，并将前景裁切到投影多边形。主视角缺深度或包围体偏小时，侧视可见物块也会被截成局部轮廓。此次既修显示语义，也增加完整侧视色块关联，不能只隐藏框后宣称算法变好。

## 新处理流程

新增独立实验配置`config/dual/temporary-hsv-side-full-debug.yaml`，继承上一阶段全图主视角分割；侧视启用：

```yaml
dual_view:
  side_complete_color_components: true
  side_hsv_split_hue_gap: 18
  side_hsv_min_value: 12
```

全图侧视HSV有色前景 → 相近色明暗面一致/明显异色分离 → 完整连通候选 → 主点云几何投影确认唯一对应 → 完整RGB掩膜 → 原LSD棱线/空间拓扑分类 → 原Top-2融合和安全门。

使用循环色相，不按亮度拆面，不按颜色或全图最近中心匹配对象。完整候选必须有足够投影支持，面积不超过画面25%、支撑交集不少于20像素或侧视最小面积10%、投影支持比例至少35%，且候选到投影的P95距离不超过尺度相关上限。支持比例参与质量约束；没有对应、同一色块有多个投影所有者、存在显著竞争色块时拒绝侧视，不强选。原投影重叠30%遮挡门保留；图像边缘截断候选侧视质量为0。

投影多边形只用于对应，不再裁切已确认的完整色块。分类裁剪边界来自完整色块并加留白，投影多边形原坐标仍保留在诊断。侧视训练提取也调用相同关联与质量接口；歧义样本明确记录失败，不混用旧缓存。

实际蓝色4253帧很暗的侧面V低于25；在侧视搜索附近，强饱和前景V≥25约17790像素，V≥12约24239像素。第一轮图片缺口明显，因此只在新实验配置把侧视V降为12，饱和度仍70；没有改变旧配置或主视角阈值，也没有补造深度。降阈值可能引入染色阴影，不保证任意背景都安全。

完整掩膜进入侧视模型和跨视角图；主相机位置、深度、抓取面的唯一来源不变。侧视不产生抓取坐标，不升级DEPTH_INVALID/NO_GRASP_SURFACE/OCCLUDED，分类仍限俯视Top-2。

## 默认显示与调试显示

默认侧视图只画绿色**观测RGB掩膜轮廓**，文字单列侧视候选类别和融合状态；绿轮廓不代表PICKABLE。不画搜索矩形、青色包围体或推断三维边。物块本来侧面为矩形时，其实际轮廓仍可能近似四边形，这不是把棱锥识别成方块。

算法仍执行LSD、跨视角拓扑和部分联合图，没有换回霍夫、没有删除棱线模型。

- `--show-side-edges`：显示RGB线段候选及未解析线，不显示包围体。
- `--show-side-geometry`：额外显示搜索框/参考包围体/深度支持投影，图例明确参考不是物理棱线。
- JSON schema v2不变，`diagnostics.dual_view`新增`side_contours_px`、`side_class_label`、`side_segmentation`（方法、归属比例、候选ID、对应原因）。候选ID只标记本帧内部连通候选，不是实体ID。

## 使用与复现

在`stereo camera`根目录运行，以下均离线读照片、无相机和机械动作：

```powershell
.\.venv\Scripts\python.exe scripts\replay_dual_application.py --config config\dual\temporary-hsv-side-full-debug.yaml --run-dir output\dual-hsv-rgb-edges-v5-20260918 --input-records output\dual-joint-v4-holdout-20260917\holdout-fusion-records.jsonl --dual-calibration output\native-calibration-debug-20260918\calibration-native.json --show-top-edges --output-dir output\dual-side-full-new-review
```

要审查真实RGB线候选，在上面添加`--show-side-edges`；只有查看参考几何时才添加`--show-side-geometry`。这两个开关仅控制标注，不改变分类或融合决策。

生成对照图（会额外保存不带OBB的棱线近景）：

```powershell
.\.venv\Scripts\python.exe scripts\compare_side_color_components.py --before output\dual-overhang-20260918\application-color-first-review\application-records.jsonl --after output\dual-side-full-new-review\application-records.jsonl --output-dir output\dual-side-full-new-comparison
```

当前最终成果在`output/dual-side-color-first-20260918/application-final-review`和`final-comparison`。`application-review`为早期V25版本，`application-low-value-review`为报错中断版本，不混用其统计。

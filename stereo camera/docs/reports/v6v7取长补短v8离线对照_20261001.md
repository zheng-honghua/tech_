# v6/v7取长补短：v8双相机离线优化

本轮将v6较稳定的分割、形状特征和角点对应，与v7改善的两路颜色识别、棱线图像验证及三维细化分开组合。冻结108组开发回归中，形状正确率从v7的44.44%恢复到71.30%，主视颜色宏召回100%、侧视97.31%，两路颜色错误接受均0；有稀疏角点的组数从2组恢复到61组。v8保持独立实验，不替换默认配置，`promotion_eligible=false`。

历史v6形状仍为74.07%，v8没有超过它。历史v6最终模型拟合420组；本轮严格隔离348拟合/72校准，训练规模和接受策略不同。比较用于判断开发取舍，不能据此分离出某一个模块的因果收益。原始照片、v6/v7模型包、默认配置、机器人控制和独立单目工程没有覆盖。

## 组合方式与取舍

| 环节 | v8采用的方法 | 依据和边界 |
|---|---|---|
| 分割与形状特征 | v6完整HSV物块/真实深度双掩膜、原中性填充几何输入 | 避免v7新掩膜/棱线语义改变形状输入；模型契约仍为legacy |
| 两路颜色 | v7固定空盘中性校正与独立稳健原型 | 原生RGB域计算，主视最终输出；侧视冲突只否决 |
| 二维棱线 | v6高召回候选＋v7原图亮度LSD验证层 | `image_verified=false`候选允许检查，不能直接成为可靠棱线 |
| 角点对应 | v6轮廓转折/非平行线交汇、投影先验和双向唯一匹配 | 保留歧义与遮挡拒绝，取消v7“必须两条验证线入射”导致的观测损失 |
| 三维细化 | v7联合重投影Gauss–Newton作为可回退步骤 | 最大单路残差增大或深度一致性失效则保留原解；物体范围门仍执行 |
| 三维棱线 | 几何支持候选另列，确认层增加两路v7图像线支持 | 不把曲面的多边形近似、纹理或仅几何自洽解释成真实直棱 |

极线3px、重投影2px、最小射线角2°、深度一致性5mm全部保持。没有逐帧平移投影框或放宽门槛。主视处理尺度0.75，原生1920×1080；侧视原生1280×720。颜色使用校正原生图，棱线使用原图；工作裁剪端点恢复为原生像素后再对应、去畸变和三角化。使用已有SDK原生匹配候选，严格投影/尺度预检仍未通过；采集哈希与该开发候选不同，不能称现场标定已验收。

## 数据、模型与复现来源

冻结原v6的420候选和108回归ID，沿用v7每批次×形状留2组的348/72划分。v8拟合348、内部校准72均有效；没有将校准组并入重训。原v7因新特征提取失败实际拟合347组，其失败仍在分母。当前180组实际应用全部检出，侧视缺失/歧义仍计unknown，没有为了改善指标过滤帧。

v8恢复原v6缓存的47维俯视、70维侧视、100维联合观测向量。侧视/联合先逆归一化，重新仅用348组估计均值、尺度并拟合模型；没有复用旧森林或把旧归一化作为新预测的参数。原top缓存与旧模型保存观测恢复最大差为3.8147×10⁻⁶，逐项标签顺序一致，420个paired-cache原RGB、深度和metadata签名核验通过。导出 `legacy-observations.npz` 与来源哈希，以便独立复现，不需要打包大体积paired-cache。

三个新几何模型明确保存legacy契约，不能静默消费v7语义特征。v7颜色文件来自此前实际查看的每色6组共24组拟合集原型，两路原样复用，`bule`只在读取时映射blue。融合策略只在72组内部校准选择，概率0.90、间隔0.12；缓存原始融合正确61/72=84.72%，接受35/72=48.61%，接受正确率100%、错误接受0。之后没有使用108回归调权重或阈值。

## 二维棱线与空间证据

复用内部24＋回归24组粗粒度开发标注，不使用108来重新选择标注或调阈值。标注由Codex实际查看原图后放置，并非人工认证真值。指标为固定容差的栅格支持像素精确率/召回，不等于逐条物理棱的准确率；主视工作图裁剪/恢复端点与v7早期原生整图消融不同，下面统一使用实际应用输出口径。

| 回归24组二维线层 | 主视精确率 / 召回 | 侧视精确率 / 召回 |
|---|---:|---:|
| v7实际应用候选 | 85.40% / 35.18% | 74.15% / 48.78% |
| v8图像验证层 | 86.88% / 36.37% | 75.32% / 49.98% |
| v8全部高召回候选 | 63.69% / 61.32% | 56.67% / 88.81% |

图像验证层两路精确率、召回小幅改善；全部候选召回提高伴随精确率下降。不能将全部候选的召回与图像验证层的精确率组合，声称同一检测器同时取得两者。v8进一步要求两路图像与几何支持，三维棱线确认数比v7少；高召回层不是可靠棱线输出，物理棱线召回没有独立三维真值可验证。

同输入空间消融固定v7缓存的两路原生掩膜、点云、原SDK候选、v6角点和对应以及全部几何门槛，仅切换三维数值细化：

|---|---:|---:|---:|
| 内部校准 | 87.50% / 40 | 87.50% / 40 | 1.344 → 1.204px |

48组中原有接受对应全部保留。实际108回放122候选点的残差P95约1.200px；v7仅2点的0.376px不能直接作为同覆盖精度比较。重投影只是自洽程度，像素扰动位置敏感性也不是定位精度。只有1个可确认非对称尖端，其余多数角点身份具有对称歧义，真实对应正确率与三维精度继续保留null。

实际查看最终算法的72内部与108回归全部30张RGB/原深度/侧视应用联系表，并查看8组v7/v8棱线近景。首次完整查看后只补充计时和细化回退诊断；最终联系表哈希须与已看图一致，否则打包拒绝。独立记录保存180组frame ID、批次、ROI、掩膜/深度、颜色、候选/确认数量、异常及联系表哈希，不修改原数据human_reviewed。

- 1738圆锥与973八面体：候选层重新出现面内线和纹理，图像验证层明显更稀疏；三维栏为空，未画成完整网格。

- 4560红四棱柱与4647黄六棱柱：保留外轮廓和部分内部候选，图像验证层能排除多条面内线；双路可靠三维栏仍多为空。

## 验证、限制与交付

全量302项pytest通过（49.14秒），新增9项覆盖旧模型输入逐像素保持、v7语义模型拒绝、高召回候选不得自动验证、细化深度失败回退、不强制两线入射角点、颜色冲突只能否决、三维候选必须具备两路图像支持。原观测导出与独立快照两条拟合路径均核验三套模型及融合策略SHA256完全相同，72校准未并入重训；解压实验ZIP到独立目录、使用包内源码与快照重新拟合也得到完全相同的四个哈希，无需原始照片来重拟合。compileall、范围diff与ZIP CRC核验通过。打包核验528组原始来源与v7审查哈希一致。实验ZIP包含源码/配置快照、三套模型、两路颜色、策略、420原始观测向量快照及来源、固定ID、180应用记录/审查、48粗标注和空间消融缓存、坐标/指纹/哈希审计、报告及复现命令。

缺独立三维真值、红色曲面/圆柱、黑色/浅蓝实拍校准、完整11类与独立C实体、真实多物块接触、目标机耗时、机器坐标及机械验收。同一开发回归已被多次查看，不能称独立测试集。保留v6分割的同时也保留其错误拆分和假候选；不是彻底完成v7原计划所有验收。新版本只作为可复现离线改进，继续 `promotion_eligible=false`。运行命令见 [v8复现指南](../v8双相机融合实验复现.md)。

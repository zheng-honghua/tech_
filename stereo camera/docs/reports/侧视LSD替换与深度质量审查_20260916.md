# 侧视 LSD 替换与深度质量审查（2026-09-16）

## 结论

侧置 USB RGB 链路已彻底移除 `HoughLinesP`。侧视内部棱线现在复用单目主链已验证的 OpenCV LSD、颜色分面边界、断线合并和拓扑清理；物块外轮廓的多边形边由分割掩膜补充。跨视角层继续保留线段端点、交汇、平行/汇聚、点云投影支持和三维包围体投影约束，侧视仍不能生成深度或抓取坐标。

深度数据并非“只拍摄未使用”。俯视 RGB-D 主链用它拟合空盘平面、形成高度图和实例、生成物块点云与38维几何/可见面拓扑特征、建立投向侧相机的三维包围体，并执行抓取面、深度有效性和运动安全检查。546组非空盘样本中只有450组通过主链，另外96组被深度/托盘主链拒绝，本身就是深度门正在工作的直接证据。

D435if 的深度没有 RGB 摄像头那种自动对焦。当前请求的原始深度为848×480，保存前由 RealSense SDK 对齐到1920×1080彩色坐标，所以彩色深度预览会显得块状、边缘发软。这是分辨率和对齐插值现象，不是镜头失焦。

## 深度数据实测审查

审查脚本逐个读取 `data/dual/temporary` 下633组 `primary-depth.npy`，没有把整批深度一次性装入内存。结果如下：

| 指标 | 结果 |
|---|---:|
| 可读取深度 | 633/633 |
| 保存尺寸/类型 | 全部1920×1080、`uint16` |
| 与保存内参尺寸不一致 | 0 |
| 全图有效率最低 / 中位 / P95 | 96.35% / 97.35% / 97.78% |
| 中央60%料盘区有效率最低 / 中位 | 94.65% / 97.23% |
| 每帧有效深度中位值范围 | 271–272 mm |
| 相邻像素完全相同比例中位 | 97.78% |
| 跨3像素局部差分P95中位 / P95 | 1.0 / 1.0 mm |

最后一项很高，符合848×480深度对齐放大到1920×1080后的同值块，不应解释为“零噪声”或“深度已对焦”。

已实际打开并检查 `output/depth-quality-audit-20260916/worst-depth-contact-sheet.jpg` 中中央有效率最低的12帧。最差帧主要来自红/绿/黄/蓝四棱柱；无效黑区集中在物块轮廓、托盘边缘和部分画面外背景。物块表面仍形成连续、与RGB位置一致的近距离区域，物块与盘底约40–50 mm的高度差清楚。没有看到整盘失深、深度与RGB大范围错位或某一批完全失效。结论是当前深度足以参与已有点云主链，但边界孔洞和对齐后的块状采样会限制精细棱线定位，不能把对齐深度当作1920×1080原生深度。

## LSD 回归结果

保持与阶段37完全相同的108张外层分组留出，重新训练侧视和跨视角模型。结果不是提升：

| 链路 | 原始准确率 | 含拒识宏召回 | 覆盖率 | 接受后准确率 | 错误接受 |
|---|---:|---:|---:|---:|---:|
| 俯视 RGB-D 候选 | 57.41% | 47.50% | 71.30% | 66.23% | 26 |
| LSD经典侧视 | 59.26% | 46.39% | 71.30% | 66.23% | 26 |
| LSD＋点云空间拓扑 | 59.26% | 39.17% | 59.26% | 67.19% | 21 |
| 最终 Top-2 融合 | 60.19% | 31.94% | 37.96% | 85.37% | 6 |

上一版含霍夫的阶段37融合原始准确率为62.04%、错误接受5张；本次分别退化1.85个百分点和1张。因此新模型只更新10类实验配置以保证代码/特征版本可运行，标准 `temporary.yaml` 仍不加载任何未推广侧视模型，比赛链路也没有替换。去掉霍夫满足了算法约束，但不能宣称准确率提升。

## 视觉审查

已实际打开并检查 `output/dual-cross-topology-lsd-holdout-v2/fusion-contact-sheets/` 的001至036全部联系表，共108个外层留出样本；另将其拼成6张总览放在 `review-overviews/` 并逐张检查。

- 大多数绿色 LSD/轮廓线贴合物块侧面边界，棱柱的顶侧面分界、棱锥汇聚边和八面体交叉棱能够保留；不再调用霍夫。
- LSD 内部棱线加轮廓多边形后，单个物块常出现约12–20条线，局部存在相邻重复短线，方向/交汇统计比旧版更密。这是侧视准确率下降的主要可见风险，后续应在独立实体数据上调合并规则，而不是恢复霍夫。
- 绿色物块在少数靠盘边姿态中仍出现侧视质量约0；黄色圆锥/棱锥有低对比度、被画面边缘截断或分割只落在小块的样本。质量门能禁用多数明显错误证据，但不能消除所有同族混淆。
- 青色三维包围体投影总体落在对应物块附近；临时外参和不完整点云仍造成部分偏移/放大。侧视线只能用于分类约束，不能成为抓取面。
- 深度图中的物块区域清楚，但物块边缘有黑色孔洞；这与单独633帧深度审查一致。

## 使用与限制

10类开发配置现在加载特征v2模型：

```text
models/experimental/side-geometry-lsd-dual-v2-observed.npz
models/experimental/cross-view-topology-lsd-dual-v2-observed.npz
models/experimental/dual-fusion-lsd-v2-observed.json
```

旧v1模型保留作阶段37复现，但特征版本检查会阻止它们被当前v2提取器误加载。当前数据仍缺圆柱、独立实体C、人工逐帧批准和多物体遮挡验收，且错误接受不为零，所以 `promotion_eligible=false`。

若希望深度边缘更细，优先方案是让物块和料盘保持在可靠工作距离、改善红外纹理/反光条件并在一致采集配置下验证更高原生深度档位；不要用锐化或无条件孔洞填充伪造物块边缘。改变深度分辨率后必须重拍空盘和全部训练/校准/留出数据，不得混用。

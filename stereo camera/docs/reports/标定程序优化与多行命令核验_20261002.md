# 标定程序优化与多行命令核验

日期：2026-10-02。修改范围为双相机工程的RGB棋盘格内参和三AprilTag外参程序，以及两个工程的现行教程命令。未改独立单目算法、机器人控制、协议v2、训练模型、当前配置或原始照片。未连接现场相机。本报告不证明新的真实三维定位精度。

## 实现变化

| 问题 | 当前行为 |
|---|---|
| 棋盘格实时headless达到数量仍一直读流 | 达到required-frames自动求解；预览模式可加auto-solve |
| 保存后的棋盘格照片缺少统一复算入口 | replay-session重新检测原图，检查尺寸及新元数据中的板规格 |
| 标定时和采集时UVC焦距设置可能不同 | 明确支持对焦、曝光、白平衡控制，并记录驱动反馈 |
| 移动／模糊／图边角点容易被记录 | 两程序共用连续停稳、目标清晰度与边界检查 |
| 同目录重启覆盖照片、重新R混入旧姿态 | 新实时运行隔离到run-*；R更新参考后隔离会话、清零姿态 |
| 失败结果覆盖已有输出 | 总是保存会话诊断；只有通过时写入输出，旧文件先备份，替换使用同目录临时文件 |
| 缩小图坐标只除一个比例 | 使用实际宽高比和像素中心映射，原尺寸细化 |
| 棋盘minAreaRect的角度在宽高交换时跳变 | 使用有序角点的首行方向生成姿态签名 |
| 三标签极线误差混入畸变、缺少双路重投影 | 去畸变像素极线残差、原始像素重投影残差和逐姿态诊断 |
| 固定标签方向错误仍可得到临时通过结果 | 检查同向／共面，八角点联合料盘位姿，并检查3 px固定角点投影P95 |
| 主空盘点云使用另一个RGB拟合内参 | 使用参考RGBD的SDK内参反投影真实深度 |
| 回放时改尺寸／内参不容易发现 | 新会话绑定实测尺寸、字典和内参哈希；核对已保存同步值 |

内参门槛仍为至少20保留帧、RMS≤0.8 px、残差P95≤2 px、覆盖包围矩形≥35%、最大倾角≥20°、倾角跨度≥12°及主点／焦距合理性。比赛档双机门槛仍为各路RMS≤0.8 px、联合P95≤3 px、尺度≤1%。临时开发档原有3.5 px／3.5%配置未改。运行时极线3 px、重投影2 px、射线角2°、深度5 mm及深度安全状态未放宽。

三标签joint_projection_p95_px现在取原像素重投影P95与去畸变极线P95的较大值，记录在board.joint_projection_metric中。旧三标签文件该字段仅由原像素极线距离产生，口径不同，不能把差值当定位精度增益。标定文件保留schema1，诊断增加在已有target／board中；协议schema2未变，旧文件可读。新求解产生新版本及哈希，应绑定新数据，不能修改旧数据的哈希使其通过。

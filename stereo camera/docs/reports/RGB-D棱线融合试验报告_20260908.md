# RGB-D 棱线融合试验报告（2026-09-08）

## 结论

实现了传统 OpenCV 的 RGB/深度逐棱融合、v4 特征模型、批量审查命令和同样本基线对照。候选没有达到推广门槛，当前推荐模型保持 `models/stable/rgbd/geometry-rgbd-multipose-v4.npz`。

## 算法与兼容性

- 深度面邻接产生内部棱候选，候选需满足线性、长度、外轮廓距离和 RGB 弱梯度支持。
- RGB 线只有在两侧有效深度带能分别稳定拟合平面，且跨平面残差或法向差支持折线时才保留；深度孔洞不能作为棱。
- 使用凸包圆度和顶点数阻止圆锥等圆滑轮廓被解释成多面体棱。
- 新增9个融合特征：数量、归一化长度、双向支持率、弱棱恢复率、平均置信度、交点、平行与汇聚比例。
- 新 NPZ 类型为 `rgbd_geometry_v4_fused_edges`；旧 v1–v3 模型继续走旧特征路径，TCP 和抓取状态格式不变。

## 数据与实测

- 使用 `data/rgbd-pilot` 的 pilot-01/02/03。495个有标签物块记录中，当前运行分割得到403个严格单实例，91个因不是单实例排除，另有1个旧RGB文件缺失。
- 嵌套留一采集批次评估中，同样本旧特征为259/403，准确率64.27%，宏召回64.51%；融合候选为244/403，准确率60.55%，宏召回60.32%，宏召回下降4.19个百分点。
- 融合候选的六棱锥召回提高4.35个百分点，但三棱柱下降28.95个百分点、圆锥下降11.36个百分点，超过单类最大回退门槛。
- multi-02/03临时已审实例由47/55降到42/55；其中三棱锥改善，但四棱锥、五棱锥、六棱柱和三棱柱有回退。该口径为同批次开发核对，不是独立准确率。
- multi-04/05共31帧，数量匹配保持26/31，整帧组成匹配由12/31降到9/31，标签数量重合保持80，unknown由26增至27。
- 同机同数据回放 P95 从935.69 ms增至1036.08 ms，增加10.73%，通过“不超过15%”的性能门槛，但准确率门槛失败。

## 视觉审查

- 实际查看 pilot-01/02/03 每类各1帧，共27个物块；帧ID完整记录在 `artifacts/evaluations/stage23/edge-audit-report.json`。最终保留81条融合棱，拒绝108条RGB候选。
- 对比初版联系表后增加了带状平面拟合、跨平面残差、外轮廓重叠、中心深度有效率和圆滑凸包过滤；候选由258条降到81条，圆锥抽样不再产生多面体棱。
- 三棱锥、五/六棱锥及正八面体的部分顶点汇聚线能找回；三棱柱、五/六棱柱的弱棱仍常被拒绝，严重深度孔洞会使面分区和线段关系不稳定。
- 实际查看 multi-02/03共20帧及multi-04/05共31帧的RGB标注和深度联系表。托盘ROI总体正确；multi-04第11、12、14帧仍有边缘碎片或多分割，若干物块有缺深度、边界截断和unknown，不能靠棱线分类修复分割输入。

## 产物、限制与验证

- 实验模型：`models/experimental/rgbd/geometry-rgbd-fused-edge-nested-candidate-20260908.npz`；同样本基线：`models/experimental/rgbd/geometry-rgbd-fused-edge-nested-baseline-20260908.npz`。二者均未替换当前模型。
- 评估报告：`artifacts/evaluations/stage23/cross-batch-nested-report.json`、`artifacts/evaluations/stage23/reviewed-comparison/`、`artifacts/evaluations/stage23/composition-comparison.json`。
- 已知限制：批次间外观差异很大，pilot-01留出结果尤其低；现有数据没有逐棱人工端点真值，多物体新批次只有组成标签。当前结果不能称为比赛泛化准确率。
- 验证：148项pytest通过；`compileall`与`git diff --check`通过。没有连接相机或机械运动，深度、同步、抓取和运动互锁门槛未放宽。

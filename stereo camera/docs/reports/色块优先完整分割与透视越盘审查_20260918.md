# 色块优先完整分割与透视越盘审查（2026-09-18）

## 版本与处理顺序

此次修改的是分割代码，使用上一轮HSV-v5模型做开发回放，**没有重训、没有生成v6模型**。原模型、照片、正式配置、原标定均保留。新增独立配置`config/dual/temporary-hsv-overhang-debug.yaml`，不自动替换v5配置。

主视角改为：全图HSV有色前景 → 连通色块 → 明显不同色相分离/相近色明暗面保持一致 → 真实深度的料盘平面归属检查 → 保留完整RGB轮廓 → 棱线/角点/点云分类 → 原抓取安全门。料盘像素边界不再提前截断色块，也不再在RGB恢复阶段二次裁切已确认归属的轮廓。

相近色合并只作用于同一连通候选，不将远处同色物块合并。色相按0–179循环处理，避免红色0/179被分成两件；亮度不是分离特征。只有两个明显不同色相群、每群不少于候选18%且足够大、保留至少98%候选像素时才分离；同色紧贴仍不能只靠颜色判断。

## 几何归属和安全

对真实有效且达到物体高度门槛的点，沿料盘平面法向投影到料盘平面，再检查投影点是否位于料盘ROI。至少需要20个或最小面积10%的真实支持像素，归属比例至少65%。这是工作空间归属证据，不是实际底部接触点，也不是抓取坐标。无效深度不产生归属证据。

归属通过后，RGB保留完整可见色块，真实深度支持掩膜保持独立。分类深度副本仍只包含真实物块深度；抓取不使用RGB补洞。全轮廓用于图像边缘截断和邻物距离检查。凹形/多件歧义候选仍回退深度分割，不能承诺全部恢复。

另发现黄色批次的冷白料盘检测只取右半盘。新配置同时比较冷白和中性白候选，按相同面积、矩形度和图像边界规则选择更完整候选；空盘平面拟合、参考ROI与运行检测统一使用新规则。原参考重叠不足50%、异常扩大、平面移位和RGB-D同步检查保留，不用直接扩大ROI绕过失配。

侧视仍由主视角真实点云投影建立对应，本轮没有实现侧视全图无约束色块恢复，也没有侧视独立深度。不能把主视角本次改动描述为完整双视角棱网重建。

## 复现和使用

在`stereo camera`工程根目录，用新配置运行只读离线回放：

```powershell
.\.venv\Scripts\python.exe scripts\replay_dual_application.py --config config\dual\temporary-hsv-overhang-debug.yaml --run-dir output\dual-hsv-rgb-edges-v5-20260918 --input-records output\dual-joint-v4-holdout-20260917\holdout-fusion-records.jsonl --dual-calibration output\native-calibration-debug-20260918\calibration-native.json --show-top-edges --output-dir output\dual-overhang-new-review
```

生成前后图与框统计：

```powershell
.\.venv\Scripts\python.exe scripts\compare_rgb_overhang.py --before output\dual-hsv-rgb-edges-v5-20260918\application-frozen108-review\application-records.jsonl --after output\dual-overhang-new-review\application-records.jsonl --output-dir output\dual-overhang-new-comparison
```

仅开发相机预览，确认当前安装/分辨率/空盘/候选外参匹配后使用；侧机索引填写实际设备索引：

```powershell
.\.venv\Scripts\python.exe -m sorting_vision.cli --config config\dual\temporary-hsv-overhang-debug.yaml camera-live --source dual --platform-id temporary --side-camera-index 1 --background-dir data\rgbd-background --rgbd-shape-model models\experimental\top-rgbd-hsv-v5-20260918.npz
```

新参数均可在配置修改：`allow_rgb_overhang: true`、`tray_white_balance_robust: true`、`hsv_split_hue_gap: 18`。默认分别false/false/0，旧配置保留原路径。18是OpenCV色相单位，约36°；不建议为了强行拆分而降低到很小。

后续匹配重训沿用上一轮`--full-rgb-instance`训练接口，替换为此次新配置、全新输出目录和模型路径，继续保留冻结108 ID；禁止混用旧v5特征缓存或覆盖旧模型。此次没有执行该重训。

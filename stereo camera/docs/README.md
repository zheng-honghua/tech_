# 文档目录

- `guides/`：安装、采集、训练、预测和视觉审查操作说明。
- `reports/`：各算法阶段的实测结果、视觉复审与未推广候选记录。

常用入口：

- [RGB-D结果颜色与字段说明](guides/RGB-D结果颜色与字段说明.md)：检测框颜色、形状缩写、安全状态、JSON 字段、联系表和棱线审查图。
- [RGB-D识别结果视觉审查流程](guides/视觉审查流程.md)：联系表生成与人工复审清单。
- [模块使用说明](guides/模块使用说明.md)：全部 Python 模块、CLI 命令、配置、离线脚本、集成方法及测试映射。
- [D435if迁移与重新标定](guides/D435if迁移与重新标定.md)：D415 换成 D435if 后的流配置、重采数据、重做标定和模型重验。
- [D435if数据集拍摄助手](guides/D435if数据集拍摄助手.md)与[D435if多物体批量测试拍摄](guides/D435if多物体批量测试拍摄.md)：当前相机的数据采集流程。
- [双视角形状与颜色数据采集完整教程](guides/双视角形状与颜色数据采集完整教程.md)：从三画面质量判断、形状/颜色真值、批次命名和50/15/15划分，到多物块拍摄、人工审查及常见故障的完整操作步骤。
- [双视角几何识别与安全融合](guides/双视角几何识别与安全融合.md)：11类注册表、双路数据、侧视KNN/RTrees、Top-2融合、MobileNetV3与双平台部署验收。

算法阶段总索引保留在仓库根目录的 `算法更新记录.md`。

# 更换平台与双视角稀疏三维复现

更新：2026-10-02。此页区分新平台准备与旧实验复现。原始照片、标定、冻结输入和模型快照是复现证据，不能任意覆盖。

## 1. 新平台的准备顺序

固定设备／料盘→确认档位与原生尺寸→两路内参→双机与料盘外参→主真实深度平面和机械外参→空盘背景→试拍检查→新数据与模型→冻结测试。

每个平台单独保存config、内参／外参、背景和采集哈希。competition不沿用temporary的像素ROI或开发放宽门。步骤见[标定教程](三AprilTag双相机采集与标定程序.md)。

## 2. 坐标约定

主原生RGB1920×1080、侧原生1280×720是历史临时档；处理scale=0.75不改变相机原生尺寸。工作图裁剪端点先恢复原生像素，去畸变后再三角化。

T_side_from_primary把主相机3D点变到侧相机；T_tray_from_primary建立料盘系；camera_to_robot为单独实测机械变换。不能把这些矩阵互换，不能将同一3D点的相机系、料盘系和机器人系数字直接比较。

## 3. 标定预检

使用已有SDK匹配候选时核对原图、裁剪、缩放、畸变和内参投影。已有历史候选仅临时档有效，严格联合投影／尺度门未通过；新平台重新测量。

check_sparse_platform的真实文件参数见CLI索引；没有对应标定、空盘、注册表和模型时不要把模板运行当验收。

## 4. 稀疏点的接受条件

稳定轮廓转折／非平行线交点产生二维候选，投影／极线、双向唯一与歧义门约束匹配，三角化后检查主深度归属和物体范围。

保持极线≤3 px、重投影≤2 px、射线夹角≥2°、主深度一致性≤5 mm。少量点的低残差可能来自大量拒识；比较残差时同时报告覆盖和数量。

v8联合重投影细化有回退，最大单路残差变坏或深度门失败保留原解。细化不能修错误对应和新标定错误。

确认旧v8产物及原照片存在，输出到新目录：

run-dir读取冻结ID、模型／策略和来源；不是新采照片目录。应用回放需要原照片，实验ZIP不包含全部原始照片。详见[v8完整复现](../v8双相机融合实验复现.md)。

## 6. 图层解释

| 图层 | 表示什么 |
|---|---|
| RGB轮廓／二维候选 | 图像观测，可能含纹理和阴影 |
| image_verified | 图像支持门通过，尚非完整三维真实性 |
| 稀疏角点／线 | 当前几何自洽的部分候选 |
| geometry_candidates_3d | 几何门通过 |
| confirmed_ridges_3d | 还具有两路图像线支持 |
| 参考OBB／投影框 | 辅助空间范围，非实物棱网 |

show-side-geometry显示参考包围体。曲面的多边形拟合、对称角点身份和遮挡部分都要保留不确定。

## 7. 质量字段与评价

每个3D点记录主相机坐标、可用料盘坐标、两路像素、证据与残差。扰动敏感性衡量像素变化对解的影响，不等于真实毫米误差。

有独立3D测量／可确认角点身份才能评估真实定位精度／对应正确率。没有真值留null或未验证，不把自洽残差写成精度。

## 8. 数据与打包

保存原图／原深度／metadata、校准来源和哈希、冻结ID、观测快照、模型契约、策略、实际看图与应用记录。来源不一致先停止复现核查，不重新标哈希“修复”。

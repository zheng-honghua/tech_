# D435if 数据集拍摄助手

`rgbd-capture-assistant`用于连续拍摄一整个有标签的RGB-D批次。相机只启动一次，可在预览窗口中切换类别；程序把RGB、原始深度、深度预览、内参和人工标签保存到同一个样本文件夹。

训练标签始终由拍摄者选择。当前识别模型不会自动修改标签，避免错误预测污染训练集。

## 启动

在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev,realsense]"

.\.venv\Scripts\python.exe -m sorting_vision.cli `
  --config "config\d435if-initial.yaml" `
  rgbd-capture-assistant `
  --dataset-root "data\rgbd-d435if" `
  --batch-id d435if-pilot-01 `
  --target-per-label 10 `
  --auto-advance `
  --color-width 1920 --color-height 1080 `
  --depth-width 848 --depth-height 480 `
  --fps 30
```

当前 D435IF 配置默认请求彩色 `1920×1080@30` 和深度 `848×480@30`，需要 USB 3 连接；这组 profile 已在当前设备上验证可启动。需要切换 profile 时，必须同时记录并固定整个训练、验证和测试实验使用的流配置。

## 按键

| 按键 | 类别或操作 |
| --- | --- |
| `0` | 空托盘 |
| `1`～`9` | 三棱柱、三棱锥、四棱锥、五棱柱、五棱锥、六棱柱、六棱锥、正八面体、圆锥 |
| `N` / `P` | 下一个/上一个类别 |
| `A` | 跳到下一个未达到目标数量的类别 |
| 空格 | 质量检查通过后保存 |
| `F` | 强制保存并在元数据中标记质量覆盖，仅用于确认门限误判时 |
| `Q` | 退出 |

下方信息栏显示当前英文类别ID、该类数量、总数量、深度有效率、画面运动量和RGB/深度时间差。只有显示`READY`时空格才会保存；手未离开、画面仍在晃动、深度有效率过低或两路图像不同步时会拒绝。当前批次还没有空托盘样本时，程序也会拒绝普通物块，防止漏拍背景。

## 拍摄流程

1. 关闭 RealSense Viewer，固定 D435if 并清空托盘。
2. 选择`0`，先拍10组空托盘。
3. 放入一个完整物块，按对应数字选择人工标签。
4. 手离开画面并等待`READY`，按空格保存。
5. 每张之间改变稳定面、旋转角度或画面位置。
6. 达到目标数量后切换下一类；全部完成后按`Q`。

重新使用相同的`dataset-root`和`batch-id`启动时，程序会从`manifest.jsonl`恢复已有计数，不会要求从零开始。不要移动、重命名或单独复制样本内部的`color.png`、`depth.npy`、`depth-preview.png`和`metadata.json`。

## 拍后检查

```powershell
.\.venv\Scripts\python.exe -m sorting_vision.cli rgbd-dataset-audit `
  --data-root "data\rgbd-d435if" `
  --output-report "output\d435if-pilot-audit.json"
```

审计完成后还必须人工查看RGB、深度预览和面拓扑诊断，确认物体完整、深度连续并且RGB与深度对齐，再开始训练。

换机后的完整校准、迁移模型和推广要求见 [D435if 迁移与重新标定](D435if迁移与重新标定.md)。原 D415 空托盘、内参、外参和颜色校准不得用于 D435if。

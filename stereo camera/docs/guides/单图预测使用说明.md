# 单张RGB图片预测教程

更新：2026-10-02。输入一张以单个物块为主的JPG／PNG，输出形状预测、置信度、拒识原因及可选图像资料。RGB预测不提供可执行三维抓取。

## 1. 环境和输入准备

```powershell
Set-Location "C:\Users\d114\Desktop\tech_\stereo camera"
.\.venv\Scripts\python.exe -m sorting_vision.cli predict-image --help
```

图片应包含完整物块及少量周围背景，避免手、过曝、严重遮挡和多个竞争对象。多个分离物块使用[场景预测](多物块场景预测使用说明.md)。照片不必放进训练目录，不能把测试图自动并入训练。

## 2. 最小命令

将data/input/object.jpg换成你的实际文件：
```powershell
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli predict-image data\input\object.jpg `
    --output-dir output\single-image-20261002
```

predict-image的图片是位置参数，不能写成detect命令的--image。默认RGB开发模型为models/stable/rgb/geometry-rgb-morph-color.npz；是否存在先用Test-Path检查。

## 3. 指定模型和后端

```powershell
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli predict-image data\input\object.jpg `
    --model models\stable\rgb\geometry-rgb-morph-color.npz `
    --backend opencv `
    --output-dir output\single-opencv-20261002
```

OpenVINO目录模型使用--backend openvino --device CPU，需安装.[cnn]及完整导出文件。auto按模型选择，报告记录实际后端。点线结构模型与普通轮廓模型的特征语义不同，不替换文件名冒充同一模型。

## 4. 输出怎么检查

--output-dir保存result.json及annotated／crop／mask等图像资料，确切文件名以result.json的artifacts和目录为准。查看原图、提取掩膜、裁剪和预测：
- 轮廓是否完整、是否包含白盘／手／背景。
- 标签是否unknown；reason是距离、间隔还是分割不足。
- confidence是模型输出，不是独立测得准确率。
- 平滑曲面的多边形近似不能单独证明真实棱数。

只有--json-only时终端打印机器可读JSON。不要把日志混入JSON文件；读取完整输出字段。

## 5. 旧托盘二维detect入口

```powershell
.\.venv\Scripts\python.exe `
    -m sorting_vision.cli detect `
    --image data\input\tray.jpg `
    --output-dir output\rgb-detect-20261002
```

detect是托盘分割／二维兼容流程，不是predict-image别名。它可选background、calibration和shape-model；四点透视标定只适用二维平面，不能代替RGB-D三维外参。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 找不到图片／模型 | 当前目录、实际路径、后缀；含空格加引号 |
| 多件只预测一个 | 改predict-scene |
| unknown | 查看掩膜和拒识原因，补姿态／校准 |
| 白色背景被识别 | 检查对象裁剪和曝光 |
| 想得到毫米／抓取位姿 | 采完整真实RGB-D，见[RGB-D教程](RGBD数据采集与训练.md) |

模型训练与字段定义见[模块说明](模块使用说明.md)、[CLI参数](CLI命令与参数索引.md)和[输出判读](RGB-D结果颜色与字段说明.md)。

# 算法更新记录

本文件按实际代码更新时间记录算法变化。每次代码更新必须追加一条记录；不能删除旧结论来掩盖失败实验，也不能把训练回放结果写成独立测试准确率。

## 版本演进基线

以后所有算法更新均在下表基础上顺序追加，从第20阶段开始。既有阶段不得重排、重新分类或覆盖；仅修改文档、测试设施和工程结构时，不占用新的算法阶段编号。

| 更新阶段 | 当时提出的需求 | 这一版采用的方法 | 相比上一版的变化 |
| --- | --- | --- | --- |
| 1．二维分拣初版 | 识别颜色、形状、位置和角度 | 背景差分、Lab颜色识别、形态学处理、轮廓几何、距离变换 | 建立最初的二维识别与抓取点接口 |
| 2．三维视觉框架版 | 物块会侧躺、倾斜，不能只看二维轮廓 | RGB-D输入、托盘平面拟合、点云几何、吸附面分析 | 从二维中心/角度升级到三维位置/法向；当时主要是框架和合成验证 |
| 3．USB/D415与运动互锁版 | 暂时只有USB相机；工具头运动时只预览 | 相机适配器、MOVING/SETTLING/READY状态机、帧差稳定检测 | 分离取流和计算；运动即清除旧结果，RGB禁止抓取 |
| 4．首批几何例图版 | 接入“几何测试_1”的7类34张图 | 主体分割、HOG、Hu矩、轮廓、边缘方向、明暗特征＋距离分类 | 从固定轮廓规则转向可训练的RGB特征模型：`geometry-rgb.npz` |
| 5．OpenCV/CNN双版本 | 想比较传统视觉与CNN | 保留NPZ模型，增加MobileNetV3-Small RGB CNN和OpenVINO接口 | 两套分类器可手动切换，不自动融合 |
| 6．内部棱线拓扑版 | 认为应根据立体物块上的棱判断类别 | CLAHE、Canny、LSD、共线合并、交点、平行/汇聚关系、可见面 | 分类证据从外轮廓扩展到内部结构：`geometry-rgb-edges.npz` |
| 7．测试2与棱线改进版 | 新增图片，继续优化 | 扩充训练样本、过滤外轮廓伪棱、面几何特征、拒识与跨集检查 | 形成edges-v3、expanded、faces等实验模型 |
| 8．单图预测与多物块版 | 希望直接输入图片；一张图里有多个物块 | `predict-image`、`predict-scene`，分割后逐个裁剪分类 | 从开发命令变为直接预测接口，并增加多实例结果输出 |
| 9．开闭运算＋色块辅助版 | 不用霍夫，利用开闭运算和色块补棱 | 形态学开闭、Lab色块划分、色面边界辅助、线段拓扑 | 改善断棱与噪声：`geometry-rgb-morph-color.npz`；未使用霍夫 |
| 10．低噪声点线结构版 | 要轮廓点线尽量干净，并找回内部漏棱 | 多边形拟合、短边剪枝、端点吸附、交点聚类、悬空线删除 | 对提取结果再做结构清理：`geometry-rgb-structure.npz` |
| 11．现有图片CNN训练版 | 传统模型效果差，实际训练CNN看看 | 使用现有图片训练RGB MobileNetV3-Small，加入数据增强 | 实际训练和比较CNN候选；没有变成点线CNN或RGB-D CNN |
| 12．D415实拍与三维结构版 | D415到位，加入深度采集和训练 | 成组保存RGB/深度/内参；三维尺寸、深度分布、局部平面与面拓扑 | 从RGB外观转向真实深度特征，建立RGB-D训练链路 |
| 13．多姿态KNN版 | 新拍不同姿态，提升跨批次识别 | 从每类单质心升级为多姿态KNN，比较各类最近的3个姿态 | 保留同类正放、侧躺、倾斜的不同特征，形成multipose系列 |
| 14．多物体批量测试版 | 批量拍摄整盘场景 | 场景成组采集、组成标签、批量回放、逐实例评测 | 从单件训练扩展到多物块场景测试；数量标签用于评测，不是强制检测出指定数量 |
| 15．白色托盘ROI版 | 只识别托盘内部和边缘 | 托盘ROI检测、RGB支持区域与深度前景联合限制 | 排除托盘外物块，减少背景杂物干扰 |
| 16．新增两轮训练版 | 用新拍摄的多物体场景继续训练测试 | 样本提取、追加多姿态样本、模型对照 | 形成后续multipose-v4等模型；混合场景标签可靠性成为新问题 |
| 17．六棱柱专项优化版 | 六棱柱识别率低 | 统一训练/推理缩放；用公制跨度和近平面占比复核部分八面体预测 | 针对六棱柱侧躺混淆增加受限规则，仍保留v4主模型 |
| 18．视觉审查驱动的分割修正版 | 根据实际图片检查漏检、重复检测 | 小碎片的距离、面积、色相、高度与连接区域约束合并 | 修复同一物块因深度断裂被拆成两件，并保留深度安全拒绝 |
| 19．最新优化建议落实版 | 分离RGB与深度、校准颜色、清理训练来源 | RGB/深度双掩膜、蓝青色标定、歧义标签确认、原始单件独立重训练 | 裁剪与颜色改善；新模型较差未替换，继续使用原v4＋新颜色配置 |

当前推荐链路为：**白色托盘ROI → 深度分割与碎片修复 → 三维几何/可见面拓扑 → 多姿态KNN v4 → 受限几何复核**。RGB完整轮廓用于颜色和展示，真实有效深度用于三维计算和抓取。第19阶段的形状开发回放结果为47/55（85.45%），不是正式比赛准确率。

## 记录格式

```text
## 阶段NN · YYYY-MM-DD：更新名称
- 目的：要解决的问题。
- 算法变化：新增、删除或调整的算法和关键门限；无算法变化时明确写“无”。
- 预期效果：修改前预期改善什么。
- 实际效果：测试集、样本数量、准确率/耗时/拒识率及与旧版对照。
- 视觉审查：实际查看的批次、帧和发现；不适用时说明原因。
- 影响范围：代码、配置和模型文件。
- 已知限制：未解决问题及不能据此宣称的能力。
- 验证：执行过的测试和结果。
```

## 2026-09-05：RGB轮廓与有效深度分离

对应阶段：19。

- 目的：解决D415深度孔洞造成的显示裁剪残缺，同时防止RGB补全被误当作真实抓取面。
- 算法变化：增加受ROI、饱和度、深度实例归属、重叠率和面积倍率约束的RGB连通域恢复；分类继续使用旧深度裁剪，点云和吸附面只使用有效深度掩膜。增加蓝色/青色Lab标定，并将歧义实例改为显式人工确认。
- 预期效果：获得更完整的RGB物块裁剪和更稳定的颜色结果，同时保持三维抓取安全门限。
- 实际效果：multi-02与multi-03共20帧、70个候选；颜色为30蓝、40青，无unknown/black。临时参考标签下，原v4修改前后均为47/55（85.45%）；独立单件重训练候选为40/55（72.73%），因此未替换v4。
- 视觉审查：检查两批20帧RGB/深度总览及70个实例裁剪。确认RGB轮廓改善、深度孔洞未被伪造；仍发现边缘截断和五/六棱柱混淆。multi-02第6–10帧共15个实例保持未确认标签。
- 影响范围：`rgb_instance.py`、`pipeline3d.py`、`types.py`、`cli.py`、颜色配置、训练与审查脚本。
- 已知限制：结果是同批次开发回放，不是正式泛化准确率；低饱和物块的RGB恢复尚未验证；两帧仍因托盘平面漂移被安全拒绝。
- 验证：135项pytest测试通过；compileall与diff检查通过。详细说明见[优化建议落实与使用说明_20260905.md](docs/reports/优化建议落实与使用说明_20260905.md)。

## 阶段20 · 2026-09-05：单件训练的严格实例筛选

- 目的：防止新采集单件帧中的手部、相邻物块或托盘深度碎片按“最大连通域”混入有标签训练集。
- 算法变化：`geometry-rgbd-train` 新增可选 `--strict-single-object`。开启时仅接受托盘 ROI 内恰有一个 RGB-D 分割实例的标注帧；检测到多个实例即拒绝并记录原因。默认行为仍保留最大 RGB-D 连通域选择，以保证旧模型可复现。
- 预期效果：减少错配标注特征对新训练候选的污染，同时不降低实时抓取安全门限。
- 实际效果：`pilot-03` 的 300 条新记录中，严格训练接受 254 个物块特征，拒绝 16 帧（2–8 个实例）。仅用新数据的独立候选在 `multi-02/03` 可临时核对的 55 个实例中为 42/55（76.36%）。以 v4 的289个样本为底座、追加这254个样本的增量候选共543个样本，为47/55（85.45%），与 v4 持平；两者均未超过 v4，因此未替换当前模型。
- 视觉审查：实际查看 `pilot-03` 的 27 帧 RGB/深度联系表，以及候选在 `multi-02/03` 的 20 帧联系表和 40 个物块裁剪。确认托盘 ROI 大多正确；`d415-000020755`、`d415-000019390`、`d415-000001745`、`d415-000002895`、`d415-000005104` 有多候选/碎片，五六棱柱与三棱柱仍有分类混淆。
- 影响范围：`geometry_rgbd_model.py`、`cli.py`、`test_geometry_models.py`、`RGBD数据采集与训练.md`；候选模型现归类在 `models/experimental/rgbd/`，包括未推广的`geometry-rgbd-v4-pilot03-strict-20260905.npz`，详细结果见[新数据视觉复审与严格训练报告_20260905.md](docs/reports/新数据视觉复审与严格训练报告_20260905.md)。
- 已知限制：严格筛选依赖当前分割结果，会拒绝深度断裂但真实只有一个物块的帧；它不是自动真值校验，也未解决多物块中的形状混淆。回放仍是开发批次，且 `multi-02` 第6–10帧标签未确认。
- 验证：新增严格筛选单测；`tests/test_geometry_models.py` 14项通过，`compileall`和`git diff --check`通过。没有启动相机或机械运动；只有 RGB-D 且 `PICKABLE`、`selected=true` 的结果才能驱动动作的规则不变。

## 阶段21 · 2026-09-05：空托盘参考约束异常ROI扩张

- 目的：新RGB-D画面中桌面和托盘边缘被并入工作区域，出现4个物块却检测出10–12件；直接加训练样本无法修复该分割错误。
- 算法变化：RGB-D标定保存可选托盘参考多边形；ROI扩张超过参考面积1.5倍才取交集，正常平移保持实时ROI；重合不足参考50%时安全拒绝并清除稳定计数。旧标定文件兼容。深度前景、三维几何/面拓扑和抓取门限不放宽。
- 预期效果：减少背景和托盘边缘误检，且避免固定像素边界裁掉正常移动的托盘物块。
- 实际效果：multi-04/05共31帧，数量匹配13→26帧，整帧形状组成完全匹配10→12帧，总候选171→116。83.87%仅为数量匹配率，不是形状准确率。旧multi-02/03临时核对仍47/55。固定交集原型虽然新帧数量匹配29/31，但旧场景裁切回归，未采用。
- 训练：495个物块清单（另55空托盘）；494可读RGB-D文件对无完全重复，1张旧RGB缺失。固定ROI试验接受425单实例，按215训练/124验证/86同次拍摄时间留出比较KNN；新候选未稳定胜过v4，未覆盖原模型。详细筛选、污染风险及口径见报告。阶段20的16个拒绝帧分母为270物块帧，不是300物块帧（另30空托盘）。
- 视觉审查：实际查看新多物块31帧、旧多物块20帧最终RGB/深度总览，以及pilot-03抽样27帧。multi-04首3帧桌面误检减少；第11/12/14帧仍有边缘碎片，multi-05第2/9帧仍重复分割。圆锥采集 `d415-000020755` 有手部干扰；仍有多面体unknown与边缘截断。
- 影响范围：`rgbd.py`、`pipeline3d.py`、`geometry_rgbd_model.py`；RGB-D测试、回放/组成评估/运行时特征调查脚本及使用文档。模型保持v4；新候选单独保存在`models/experimental/rgbd/`。见[深度识别优化报告_20260905.md](docs/reports/深度识别优化报告_20260905.md)。
- 已知限制：开发回放不是独立准确率；没有逐实例真值；正常范围内的轻度ROI扩张仍存在。旧标定没有参考字段时不会自动启用新约束；硬件位置明显变化需重新标定。本次未连接相机或机械运动。
- 验证：最终141项pytest通过；compileall和git diff --check通过。保存/加载兼容、正常平移、异常扩张、无深度拒绝和运动联锁测试通过。

## 阶段22 · 2026-09-06：三维几何与可见面拓扑的可选加权训练

- 目的：继续优化已有代码的形状混淆，检查可见面拓扑噪声与三维尺寸、深度分布等权计算距离的影响。
- 算法变化：`DepthGeometryModel.fit` 支持正特征权重，归一后折入NPZ缩放并重学距离拒识门限；省略时保持旧行为，兼容v3模型。新增训练坏输入检查及NaN/空特征明确拒识。候选基础20维权重1、拓扑权重0.25，保留真实深度使用。
- 预期效果：降低不稳定面拓扑对分类的影响，减少多面体误判与拒识；不是降低深度或抓取安全门限。
- 实际效果：同口径单件验证96/124→105/124，错判6→5；同次拍摄末段61/86→68/86。旧多场景临时已审实例47/55→50/55，但新多场景整帧组成12/31→10/31。因此候选不替换v4，阶段21已验证的ROI改进继续使用。不能把90.91%称为整体准确率。
- 数据：沿用固定ROI调查的425特征（215训练/124验证/86时间留出），候选继承289个v4特征共504样本。缓存RGB-D文件对无完全重复，但v4历史数据可能与旧验证集重叠；非独立泛化测试。新多场景31帧没有完全重复RGB-D文件对。
- 视觉审查：实际查看multi-04/05全部31帧、multi-02/03全部20帧以及pilot-03九类抽样27帧的RGB/深度联系表和旧multi-03的40个裁剪；确认部分旧六棱柱/三棱锥拒识改善，同时新场景有错误分类，手部、边界碎片、拆分和孔洞问题仍在。
- 影响范围：`geometry_rgbd_model.py`、`test_rgbd_dataset.py`、`probe_depth_metric.py`、`probe_depth_classification.py`及使用记录。实验模型`geometry-rgbd-weighted-candidate-20260906.npz`归类在`models/experimental/rgbd/`，没有覆盖原模型。见[深度加权分类试验报告_20260906.md](docs/reports/深度加权分类试验报告_20260906.md)。
- 已知限制：固定ROI训练特征与最终自适应路径存在差异；旧v4来源不完备；新多场景缺逐实例真值。RBF核分类和unknown填补仅作离线诊断，未部署。
- 验证：143项pytest通过，compileall和git diff --check通过；无相机/机械动作，原深度和运动安全约束不变。

## 阶段23 · 2026-09-08：RGB-D逐棱融合候选

- 目的：将二维弱棱线与真实深度面逐条对应，降低棱柱、棱锥等同色多面体的漏棱和形状混淆。
- 算法变化：增加深度面边界候选、低阈值Lab边缘、双侧带状平面拟合、跨平面残差、RGB/深度双向支持、线段合并和圆滑凸包过滤；追加9个融合特征及 `rgbd_geometry_v4_fused_edges` 模型格式。旧v1–v3模型仍走原路径。
- 预期效果：找回弱明暗棱，同时拒绝阴影、外轮廓、深度孔洞和曲面假棱，在不放宽安全门槛的前提下提升跨批次形状召回。
- 实际效果：403个严格单实例的嵌套留批评估中，旧特征259/403、宏召回64.51%，融合候选244/403、宏召回60.32%，下降4.19个百分点。multi-02/03临时已审实例47/55→42/55；multi-04/05整帧组成12/31→9/31，数量匹配维持26/31。P95耗时935.69→1036.08 ms，增加10.73%。候选未推广，当前仍使用v4。
